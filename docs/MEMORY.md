> Living log of engineering decisions, constraints, and session notes. Update after every task.

## 1. Context & Principles

BaseBuildStack is a responsive web app (mobile + desktop, installable PWA) for interview preparation.
Key invariant: deterministic code decides what is true (scoring, XP, puzzle/bug validity). Open-weight LLMs only personalize and grade free text. All features work with LLM disabled.
